# 🤖 RAG Knowledge Assistant (Local & Google Drive)

A lightweight Streamlit RAG application supporting **PDF, DOCX, TXT, and Markdown** files from **Local Uploads** and **Google Drive**.

## Features
- **Multi-Format Extraction:** Extract structured text with filename and page metadata.
- **Smart Chunking:** Splits documents into overlapping chunks.
- **FAISS & Sentence Transformers:** Generates high-speed vector embeddings.
- **Hybrid Search:** Combines semantic vector similarity with keyword score matching.
- **Groq LLM Integration:** Powered by `llama-3.3-70b-versatile` with strict grounding.
